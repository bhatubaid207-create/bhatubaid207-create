### IBM HR Analytics — Employee Attrition Prediction & Workforce Risk Analysis

An end-to-end HR Analytics project combining **Python, Machine Learning and Power BI** to analyze employee attrition and develop a predictive workforce risk framework.

**Project Highlights:**
- Analyzed 1,470 employee records
- Conducted exploratory HR and workforce analysis
- Engineered HR-specific analytical features

- Achieved **0.803 ROC-AUC**

- Developed employee-level workforce risk scores
- Identified High, Moderate and Low risk workforce segments
- Built an interactive Power BI HR Analytics dashboard
